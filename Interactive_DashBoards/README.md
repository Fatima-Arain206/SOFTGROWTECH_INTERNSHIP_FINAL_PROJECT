# Interactive Data Dashboard

## 📌 Overview
This project creates an interactive dashboard that visualizes data using graphs and charts, helping users understand the underlying data easily at a glance. It was completed as the **Final Project** of the Data Analysis Internship at **SoftGrowTech**.

## 🎯 Objective
- Build a dashboard that visualizes key metrics using graphs and charts
- Make the dashboard easy to understand for any user, not just technical audiences
- Combine multiple visualizations into a single, cohesive view

## 🛠️ Tools & Technologies
- Tableau
- Python (Pandas, Matplotlib/Seaborn) for supporting analysis

## 📂 Dataset
Dataset sourced from [Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) — IBM HR Analytics Employee Attrition Dataset.

## 🔍 Steps Performed
1. Loaded and cleaned the dataset
2. Explored key metrics (attrition rate, department, income, job satisfaction)
3. Built individual charts/sheets for each key metric
4. Combined all visualizations into a single interactive dashboard
5. Added filters/interactivity to make the dashboard user-friendly
