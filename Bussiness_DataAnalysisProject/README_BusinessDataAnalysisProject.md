# Business Data Analysis Project

## 📌 Overview
This project analyzes a real-world business dataset to extract meaningful insights and clearly explain the patterns and trends found within it. It was completed as the **Final Project** of the Data Analysis Internship at **SoftGrowTech**.

## 🎯 Objective
- Analyze a real-world dataset (sales/business data)
- Generate insights using charts and visual reports
- Clearly explain patterns and trends found in the data

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## 📂 Dataset
Dataset sourced from [Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) — Superstore Dataset.

## 🔍 Steps Performed
1. Loaded and explored the dataset using Pandas
2. Cleaned data (handled missing values, fixed data types)
3. Performed exploratory data analysis (EDA) across sales, profit, region, and category
4. Identified key patterns and trends in business performance
5. Created visualizations (bar, line charts) to present findings clearly
